# Los iconos de las apps van aqui

Un PNG cuadrado por app, nombrado con su applicationId exacto:

    com.marc.gymplan100.png
    com.marcm.cronicasapetito.png

512x512 px es lo recomendable. Tambien vale .webp.

No se pueden sacar del APK: las apps modernas llevan el icono como vector
adaptativo, no como imagen. Si falta el fichero, el generador avisa y publica
igual, y la tienda pinta su marcador de marca en esa app.
