DracApps

Las apps de Marc, para los suyos.

Esto no es una web de descargas: es el catálogo que lee la app DracApps. Si te han dado un móvil con la tienda instalada, ábrela y ya está.

Para curiosos

El catálogo se publica aquí: catalogo.json

Cada app se descarga de las Releases de su propio repositorio, con su huella SHA-256 publicada en el catálogo. La tienda comprueba esa huella antes de instalar nada; si no cuadra, borra el fichero y no instala.
